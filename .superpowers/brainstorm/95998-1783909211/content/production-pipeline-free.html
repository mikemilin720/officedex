Newcomer rule: never record the whole 85 seconds in one take

Capture 8–12 short clips, each showing one action. If a click or animation fails, re-record only that clip. The editor will make them feel continuous.

Fallbacks

  • If CapCut is unavailable, use DaVinci Resolve Free; it is more powerful but harder to learn.
  • If AI voice quota is unavailable, use macOS system speech temporarily for timing, then replace it before release.
  • If live generation is slow or unpredictable, record a prepared task and edit out waiting time; never fake features that the product does not perform.

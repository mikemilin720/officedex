Demo prompt shown on screen

Create a launch strategy presentation for a new AI productivity app. Define the target audience, positioning, launch channels, a 90-day rollout plan, and success metrics. Make it clear, visual, and suitable for an executive review.
Before recording
  • Use an English-only demo workspace and clean chat history.
  • Hide API keys, account details, local paths, notifications, and the macOS menu bar clock if possible.
  • Set display scaling and app window size once; never change them mid-project.
  • Prepare the successful final deck before recording any shot.
  • Record cursor movements slowly, with a short pause before every click.
Release QA
  • Every stated feature is visibly demonstrated in the current build.
  • All captions remain readable on a phone at normal X playback size.
  • Narration is louder than music; no clipping or abrupt cuts.
  • The CTA and product name stay visible for at least 2.5 seconds.
  • Test autoplay-muted: the whole story still makes sense without sound.

If live generation misbehaves

Do not keep retrying during the recording session. Use the prepared task and capture each verified state separately. Shorten real waiting periods with honest time compression; do not fabricate screens or claim capabilities that are not present.
